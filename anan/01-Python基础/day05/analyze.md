# 银行个人消费信贷智能辅助初审 Prompt 测试与问题分析报告

## 1. 作业目标

本次实战围绕银行个人消费信贷初审场景，采用工程化 Prompt 对信贷申请进行结构化辅助初审。Prompt 按 L1 元指令、L2 行为约束、L3 JSON Schema、L4 Few-shot 四层结构设计，并通过五步分阶段分析流程，对申请资料完整性、偿债能力、信用风险、其他风险因素及综合决策进行逐项处理。

## 2. 测试环境

- API 服务：硅基流动（SiliconFlow）
- 测试模型：`deepseek-ai/DeepSeek-V4-Flash`
- 测试方式：Python 脚本逐条调用模型并自动校验结果
- 输出模式：JSON Object
- 温度参数：`temperature=0`
- 测试用例：20 条

## 3. Prompt 设计说明

### 3.1 L1 元指令

将模型设定为银行个人消费信贷初审分析专家，明确任务范围为申请资料检查、DTI 计算、风险识别、人工复核判断及综合初审决策。

### 3.2 L2 行为约束

通过禁止虚构信息、禁止擅自补全缺失字段、信息不足转人工复核、固定决策优先级以及限定输出范围等约束，降低模型自由发挥带来的不确定性。

### 3.3 L3 JSON Schema

对 `decision`、`risk_level`、`dti`、`analysis_steps`、`risk_factors`、`missing_information`、`manual_review_required`、`summary` 等字段进行结构化约束，并限制枚举值、必填字段、数组长度和额外字段。

### 3.4 L4 Few-shot

设置 PASS、REJECT、MANUAL_REVIEW 三种代表性示例，使模型能够对齐不同决策分支的输入输出模式。

### 3.5 分步骤分析流程

分析流程固定为五步：信息完整性检查 → DTI 偿债能力分析 → 严重信用与欺诈风险检查 → 其他风险因素检查 → 综合决策。每一步均在 `analysis_steps` 中返回判断结果和核心依据。

## 4. 测试集设计

测试集共 20 条，覆盖正常场景、边界场景和异常场景。重点验证 DTI、逾期次数、最大逾期天数、征信查询次数、未结清贷款数量、就业稳定性、黑名单以及字段缺失或非法值等情况。

其中多组用例采用临界值成对设计，例如 DTI 40%/略高于40%、60%/高于60%，最大逾期 29/30/90 天，征信查询 5/6 次，贷款 3/4 笔，用于确认模型是否严格执行边界条件。

## 7. 结果分析

### 7.1 正常场景

普通低风险、高收入低负债、轻微逾期、较低征信查询次数及较少未结清贷款等正常场景均输出 PASS，模型能够根据规则正确识别未触发风险阈值的申请。

### 7.2 边界场景

边界值测试全部符合预期：DTI=0.40 时通过，DTI=0.41 时转人工复核；DTI=0.60 时人工复核，DTI=0.62 时拒绝；最大逾期 29 天通过、30 天人工复核、90 天拒绝；征信查询 5 次通过、6 次人工复核；未结清贷款 3 笔通过、4 笔人工复核。

说明 Prompt 中的大小关系、等号边界以及决策优先级能够被模型稳定执行。

### 7.3 异常场景

黑名单命中能够触发 REJECT；月收入字段缺失以及月收入为负数时均进入 MANUAL_REVIEW，且 `dti` 返回 `null`，没有对缺失或非法数据进行自行补全。

### 7.4 结构化输出

20 条结果均通过 Schema 校验，`decision`、`risk_level`、`analysis_steps`、`risk_factors`、`missing_information` 等字段完整，说明结构化约束能够有效控制输出形态。

## 8. Bad Case 与问题分析

本轮 20 条测试中未出现决策错误或结构错误，因此没有形成实际业务 Bad Case。从测试结果看，当前 Prompt 对单一规则、临界值和基础异常输入的约束效果较稳定。

但测试集仍有继续扩展空间：当前主要采用单一变量测试，后续可补充多个风险条件同时命中、字符串代替数字、布尔值类型错误、额外字段、null 值以及更复杂的组合风险场景。这些场景可用于进一步验证 Prompt 在复杂输入下的规则优先级和结构稳定性。

## 9. Prompt 迭代思路

Prompt 后续优化采用“编写 → 测试 → 分析 Bad Case → 修改单一变量 → 全量回归”的闭环。若出现边界判断错误，则优先强化数值区间；若出现结构错误，则强化 JSON Schema；若出现决策优先级错误，则进一步明确 REJECT > MANUAL_REVIEW > PASS；若某类场景理解不稳定，则补充对应 Few-shot 示例后重新执行全量测试。

## 10. 总结

本次共完成 20 条银行个人消费信贷初审测试，决策正确 20 条，决策准确率为 100.00%；Schema 校验通过 20 条，符合率为 100.00%。正常、边界和异常测试结果均与预期一致。测试结果表明，采用四层 Prompt 结构、量化业务规则、分步骤分析和 JSON Schema 约束后，模型能够较稳定地按照预设业务逻辑完成信贷初审，并输出可解析、可追溯的结构化结果。
